홀리클럽 계정 삭제 요청

이 페이지는 홀리클럽(HolyClub) 계정과 관련 데이터의 삭제를 요청하는 곳입니다. 홀리클럽은 에이엔에이치(A&H)가 운영합니다.

1. 앱에서 바로 삭제하기

가장 빠른 방법입니다.

  1. 홀리클럽 앱에 로그인합니다.
  2. 설정 › 회원 탈퇴로 들어갑니다.
  3. 안내를 읽고 탈퇴를 신청합니다.
  • 기본: 30일 동안 다시 로그인하면 복구할 수 있고, 30일이 지나면 모두 삭제됩니다.
  • 즉시 완전 삭제: 확인란에 체크하면 복구 기간 없이 바로 삭제됩니다.

2. 앱 없이 이메일로 요청하기

앱을 지웠거나 로그인할 수 없어도 요청할 수 있습니다.

계정 삭제 요청 메일 보내기

메일에 아래 내용을 적어 주세요.

  • 가입할 때 쓴 이메일 주소
  • 로그인 방식(Google · Apple · Kakao · 이메일 중 하나)
  • 앱에 표시되던 이름(선택)

본인 확인. 요청을 받으면 가입된 이메일 주소로 확인 메일을 보내 드립니다. 그 메일에 회신해 주시면 본인 확인이 끝납니다. 요청 메일의 보낸 주소만 보고 삭제하지 않으며, 비밀번호 · 인증번호 · 신분증은 요구하지 않습니다. 확인 메일에 회신이 없으면 삭제하지 않습니다.

처리 기간. 접수 후 3영업일 안에 확인 메일을 보내고, 회신을 확인한 뒤 10일 안에 삭제를 마칩니다. 이메일 요청은 30일 복구 기간 없이 바로 완전 삭제하며, 끝나면 이메일로 알려 드립니다.

3. 삭제되는 데이터

  • 계정과 로그인 연결. Apple 계정 쪽 연결은 따로 해제를 요청하며, 자동으로 해제되지 않으면 Apple 계정 설정에서 직접 해제하는 방법을 안내합니다
  • 이름 · 프로필 사진 · 리그 닉네임, 교회 · 그룹 소속과 역할
  • 기도 · 성경 읽음 · 묵상과 노트 · 루틴 · 훈련 등 모든 기록, 연속 기록 · 점수 · 뱃지
  • 죄와의 싸움 · 산상수훈 기록(죄와의 싸움은 탈퇴 신청 즉시 삭제되어 복구되지 않음)
  • 피드에 올린 글 · 댓글 · 반응 · 첨부 사진의 본문까지
  • 기존 자녀 루틴과 기록
  • 알림 기기 등록, 동의 기록

4. 예외적으로 남는 데이터

항목남는 이유기간
이미 보낸 인증 이메일과 발송 기록(Resend, 미국)발송 업체의 보관 기준최대 30일
다른 이용자가 자기 기록으로 가져간 중보 기도제목가져간 사람의 기록이 됨. 원래 작성자 표시와 연결은 지움가져간 사람이 지울 때까지
백업장애 복구용. 삭제된 정보를 되살리는 데 쓰지 않음최대 30일 뒤 자동 만료
서버 운영 로그(접속 IP · 시각)보안과 오류 확인90일
삭제 요청 · 문의 메일처리했다는 기록처리 완료 후 1년
이용 제한을 받은 계정의 이메일 확인값(복원할 수 없는 해시)과 제한 이력재가입 악용 방지1년

다른 이용자가 화면을 캡처한 것처럼 홀리클럽 밖에 있는 사본은 지울 수 없습니다.

계정은 두고 일부만 지우고 싶다면

  • 기록 하나: 앱에서 해당 기록을 열어 삭제하면 바로 지워집니다.
  • 신앙 정보 처리 동의 철회: 앱의 설정 › 개인정보 동의 관리에서 할 수 있습니다. 철회하면 새 기록이 멈추고 기존 기록은 본인만 보게 되지만, 자동으로 삭제되지는 않습니다. 지우려면 위의 계정 삭제를 이용하세요.
